# Goal

**Kid Verbal** is a web app for a parent to manage and track their children's learning across multiple subjects.

## Primary Purpose

Help kids improve academic skills through structured practice, testing, and parent or AI -guided study — covering vocabulary, reading comprehension, math, writing, and science.

## Target Users

- **Parent (1 account):** Creates content, assigns work, reviews results, manages learning plans
- **Children (multiple profiles):** Complete assigned study sessions, tests, and reading assignments

## Core Value Propositions

1. **Centralized learning hub** — one app for vocab, reading, math, writing, science
2. **Parent-controlled** — parent creates all assignments and reviews all work
3. **Structured progression** — learning plans bundle multiple activities into daily assignments
4. **Immediate feedback** — auto-grading for objective questions, parent review for subjective work
5. **Reinforced memory** — parent or AI pick weak spots in subjects for repeated practice to achieve enforced memorization
6. **Access everywhere** -- parent or kid can access app from their computers via internet. production App deployed on OCI instance and has openAI api dependency for AI features

## Non-Goals

- Not a general-purpose LMS — designed for own family's use
- AI assisted content — parent curates all material with help of AI (e.g., AI come up questions and answers to reading assignments)
- No social features beyond sibling leaderboard
